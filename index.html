03 · Workflow

How do 9 agents help you?

I write code in VS Code and pair with Claude Code. An orchestrator agent hands each piece of a task to one specialist, one owner per file, and nothing is called done before the review gate.

AgentModelOwns
orchestratorInheritsSplits the task, dispatches specialists, reconciles results
researcherHaikuWhere code lives, how a flow works, the ticket and API contract, read-only
data-developerSonnetAPI clients, models, repositories, services, DI, native source
ui-developerInheritsPages, widgets, controllers, bindings, animations, routes
testerSonnetEverything under test/: unit, widget and controller tests, mocks, coverage
lensa-reviewerSonnetSelf-review against the merge quality gate, read-only, writes the MR description
release-engineerSonnetCI, fastlane, Gradle, Podfile, Xcode, signing, dependencies
ticket-managerHaikuCreating and splitting tickets in YouTrack
project-managerSonnetPlans, reports, retros, README and tuning the agents themselves
